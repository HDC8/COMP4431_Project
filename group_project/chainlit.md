# COMP4431 Group Project

本地运行的 AI 助手，全部在你自己电脑上跑：

- **打字** → 本地 Ollama 模型（`qwen3:8b`）流式回答
- **说话** → 点输入框左边的波形按钮录音，腾讯云一句话识别转成文字
- **回答会自动朗读**（`edge-tts`），左边的 Live2D 形象同步做口型

## 小提示

- 回复语言跟随提问语言，中文问就中文答、英文问就英文答。
- 输入框旁边的 **设置** 里可以关掉语音朗读，也可以切换语音识别语言（中文 / English）。
- 朗读时会有一个 **停止 / Stop** 按钮；播完后对话里会出现可回放的播放器。
- 语音识别需要 `.env` 里配好腾讯云密钥，否则只能用打字。
